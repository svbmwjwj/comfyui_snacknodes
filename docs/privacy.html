ComfyUI SnackNodes · comfyui-snacknodes

Privacy Policy
隐私政策

Last updated / 最后更新：2026-11-01

ComfyUI SnackNodes ("Save to Cloud Drive", comfyui-snacknodes) is an open-source ComfyUI custom node. It runs entirely on the machine where you run ComfyUI. The developers operate no servers and receive no data from you.

What the app accesses

  • Google Drive, scope drive.file only. The app can see and change only the files and folders it created itself. It cannot read, list or modify any other file in your Google Drive.
  • It uses this access solely to create folders and upload the files you choose to save from ComfyUI (images, videos, other output files) into your own Google Drive, and, when you use encryption, to read the Cryptomator vault files it created there.
  • WebDAV servers and Aliyun Drive are accessed the same way, only to upload the files you choose.

Where data is stored

  • OAuth tokens and, if you enable encryption, the unlocked vault keys are stored only on your machine, in ~/.config/comfyui_snacknodes/cloud_drive.json (file mode 600). They are never written into workflows and never sent anywhere except to the storage provider's official API.
  • Your files go directly from your machine to your storage. With encryption enabled they are encrypted on your machine before upload.
  • Vault passwords are never stored.

Sharing

No data is sold, shared with, or transferred to the developers or any third party. There is no analytics, telemetry or advertising.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting your data / revoking access

  • Run python auth.py logout google_drive to delete the stored tokens and vault keys from your machine.
  • Revoke the app's access at any time at myaccount.google.com/permissions.
  • Files the app uploaded stay in your Drive under your control; delete them like any other file.

Contact

Open an issue at github.com/svbmwjwj/comfyui_snacknodes/issues.
